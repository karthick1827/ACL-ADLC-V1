Q: Why is the 'Proceed to Next Step' button disabled?

The button is locked whenever the current active file has status: In Review or status: Rejected. Once the manager changes the status to Approved and saves/updates, the button immediately unlocks.

Q: How does VS Code synchronization work?

When you click 'Proceed to Next Step' or edit in Markdown Studio, changes are written directly to disk on your computer. VS Code instantly detects disk modifications and updates your editor in real time.

Q: How do I choose between Architecture and UX?

When your PRD is approved, clicking Proceed opens the suggestion modal. If your next priority is API schemas and database contracts, choose Architecture Spine. If your focus is screen layouts and design tokens, choose UX Design System.
